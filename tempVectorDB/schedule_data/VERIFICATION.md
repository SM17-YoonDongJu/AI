# 장해분류표(부표3) 추출·버전 확정 검증 리포트

- 대상: 금감원 보험업감독업무시행세칙 별표15(표준약관) `<부표 3>` 장해분류표(생명보험)
- 원본: `schedule_data/raw/`의 HWP 3판 + 현행 PDF + KIRI 2017 신구대조
- 추출 경로: HWP → `hwp5html`(표 구조 보존) → `extract_buhyo3.py`(부표3 구간 덤프) →
  `parse_schedule.py`(항목·지급률 페어링, 개수 검증) → `generate_md.py`(파서용 md)
- 산출 md: `schedule/2005/`, `schedule/2018_04/`, `schedule/2025_06/` × `disability_schedule.md`

> **원칙:** 지급률은 원문 그대로. 원문에 없는 값은 만들지 않았다. 병합셀은 항목수=지급률수가
> 일치할 때만 위치기준으로 페어링했고, 불일치 시 TODO로 남긴다(전 표 일치 → 아래 참조).
