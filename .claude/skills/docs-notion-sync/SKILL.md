# Docs ↔ Notion Sync (Notion → docs)

`.claude/docs/`의 아키텍처 문서를 Notion 원본과 일치시킨다. **Notion이 진실의 원천(source of truth)**이며 방향은 **Notion → docs (단방향 풀)**다. 로컬 docs는 항상 Notion을 따라간다.

이 동기화는 Notion MCP(`mcp__notion__notion-fetch`)를 쓰므로 Claude가 직접 수행한다(순수 bash 스크립트로는 불가).

## 대상 파일
`.claude/docs/*.md`. 각 파일 상단에 Notion 링크가 있으며 표기가 조금씩 다르다:
- `## 노션 링크: <URL>` / `## 노션 링크:<URL>` / `## notion 링크: <URL>`

URL 끝의 32자리 hex가 Notion 페이지 ID다 (예: `...37530798f08f8175af29f28aba511dd6`).

## 동기화 절차
각 docs 파일에 대해:
1. **링크 파싱** — 상단 링크 라인에서 페이지 ID(마지막 32자리 hex)를 추출한다. 링크가 없으면(예: 비어있는 `05`) **건너뛰고** 보고에 "링크 없음"으로 남긴다 — 추측으로 페이지를 매핑하지 않는다.
2. **Notion 페치** — `mcp__notion__notion-fetch`에 ID(또는 URL)를 넘겨 페이지 본문을 가져온다.
3. **비교** — 가져온 본문과 로컬 파일 본문(링크 라인 이후)을 비교한다. 동일하면 건너뛴다(불필요한 쓰기 방지).
4. **갱신** — 다르면 로컬 파일을 **[링크 라인 보존] + [Notion 최신 본문]**으로 덮어쓴다.
5. **보고** — 파일별 결과(갱신됨 / 동일 / 링크없음 / 실패)를 요약한다.

## 원칙 (왜 이렇게 하는가)
- **단방향(Notion → docs)**: 로컬 docs 변경을 Notion으로 밀어올리지 않는다. 로컬에서 편집했더라도 Notion 내용으로 덮어쓴다 — 그것이 "풀"의 정의다. 양방향/푸시가 필요하면 사용자에게 먼저 확인한다.
- **이미지 presigned URL 무시**: Notion 본문의 S3 이미지 URL은 서명(`X-Amz-*`)이 매 페치마다 바뀐다. 서명만 다른 것을 변경으로 오인해 매번 덮어쓰지 않도록, 비교 시 presigned 쿼리스트링을 정규화하거나 이미지 URL 차이는 무시한다.
- **손실 경고**: 로컬에만 있던 수동 메모는 덮어쓰기로 사라질 수 있다. 본문이 크게 달라 로컬 고유 내용이 의심되면, 덮어쓰기 전 차이를 보고에 명시한다.
- **부분 실패 허용**: 한 파일 페치 실패(권한·네트워크) 시 1회 재시도 후 해당 파일만 건너뛰고 보고에 실패로 남긴다. 나머지는 계속 진행한다.
- **빈 파일 유지**: Notion 원본이 비어있으면(예: 05) 로컬도 비운 채 둔다.

## 페이지 ID 추출
URL 형태는 `https://app.notion.com/p/<slug>-<32hexId>` 또는 `.../p/<32hexId>`. 마지막 32자리 hex를 정규식으로 잡으면 된다. `notion-fetch`에는 ID·URL 어느 쪽을 넘겨도 된다.

현재 docs ↔ 페이지 매핑(참고용, 실제로는 파일에서 파싱):
- `02_ocr.md` → 37530798f08f8175af29f28aba511dd6
- `04_hybridRag.md` → 37530798f08f81c0b591c210c3f46212
- `05_langGraphAgent.md` → (링크 없음/빈 파일 — 건너뜀)
- `06_guardrail.md` → 37530798f08f81768a47fb1e04f447fe
- `12_chatbot.md` → 37530798f08f81e8af55c6c27fd144f0

## 검증
- 각 docs 파일 상단 링크 라인이 보존됐는가.
- 갱신된 파일 본문이 Notion 최신과 일치하는가(이미지 서명 차이 제외).
- 링크 없는 파일을 임의 매핑하지 않았는가.
- 보고에 파일별 상태가 모두 표기됐는가.

## 세션 시작 자동 실행
이 스킬은 SessionStart 훅(`.claude/settings.local.json`)에 의해 세션 시작 시 호출되도록 연결되어 있다. 훅이 주입한 안내를 보면 즉시 이 절차를 수행한다. 수동으로도 "노션 동기화"로 트리거할 수 있다.
