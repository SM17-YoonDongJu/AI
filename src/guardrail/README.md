# guardrail — 가드레일 (06)

`report_worker`·`chatbot`이 **함수 호출**로 공유하는 공용 모듈. 개인정보보호·법적 안전성이 도메인 핵심 제약이라 **필수 경로**다. 단계별 함수로 쪼개 호출자가 필요한 것만 조립한다.

## 3단계

| 단계 | 내용 |
|---|---|
| **입력** | 정규식+NER로 PII 마스킹(주민번호 **앞 6자리만 보존**), 보험·법률 도메인 외 질문 차단 |
| **생성** | 단정적 금액 표현 → "참고 추정 범위"로 치환, 모든 사실 주장에 `[조항][판례]` 인용 강제 |
| **출력** | 법적 고지문 삽입 + **LLM Judge(리포트 전용)**: 인용↔원문 검증, 불일치 섹션 치환. **챗봇엔 LLM Judge 미적용** |

## 의존 / 주의

- `core.ai_client`(LLM Judge) · 로컬 NER 모델
- **PII 마스킹 규칙은 `ocr_worker` 입력단과 동일**해야 한다(어긋나면 한쪽이 PII 유출). 정의 공유.
- 마스킹 전 원문을 로그에 남기지 않는다.
